💡 使用說明與技術聲明

本工具採用網頁 Web Audio API 的 Fast Fourier Transform (FFT) 分析聲音振幅，並根據麥克風訊號計算相對分貝值。受限於各硬體麥克風感光度與增益差異，數據適合做為環境音量變化之相對參考，非法定檢驗標準。聲音串流 100% 於本機分析處理，絕不錄音或上傳伺服器！
